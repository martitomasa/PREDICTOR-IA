Una pàgina interactiva que converteix un model predictiu basat en UCI Wine Quality en una experiència visual refinada per al sector vitivinícola. Ajusta els paràmetres del raïm, del procés de fermentació i de l'ambient, i mira com respon la predicció de qualitat.

Predictor d'IA

La predicció es basa en regressions entrenades amb més de 6.400 exemples de vins reals. Aquesta interfície utilitza pesos derivats directament de models estadístics per oferir un resultat interpretatiu.

Metodologia

El predictor es basa en dues línies de càlcul:

  • Regressió lineal per estimar la qualitat numèrica.
  • Logistic regression per calcular la probabilitat que el vi puntuï com a alt.

Codi del model

Aquest fragment mostra la lògica de predicció que alimenta la interfície. Tot està calculat amb pesos obtinguts de dades reals.

const model = {
  intercept: -1.9039,
  coefficients: {
    alcohol: 0.7026,
    density: -0.8774,
    residual_sugar: 0.8149,
    volatile_acidity: -0.5543,
    citric_acid: -0.0453,
    chlorides: -0.2197,
    free_sulfur_dioxide: 0.2251,
    total_sulfur_dioxide: -0.3278,
    pH: 0.3738,
    sulphates: 0.3663,
    fixed_acidity: 0.5516
  }
};

function predictProbability(features) {
  const scaled = standardize(features);
  let score = model.intercept;
  Object.keys(model.coefficients).forEach(key => {
    score += model.coefficients[key] * scaled[key];
  });
  return 1 / (1 + Math.exp(-score));
}

Resultats i impacte

El model ha estat dissenyat per convertir els paràmetres de vinya en decisions operatives clares.

  • Major visibilitat en el control de qualitat durant la fermentació.
  • Ràpida validació de combinacions de característica abans de produir lots.
  • Suporta decisions d'optimització de collita i selecció de barriques.
